Decompiling the data — the other 90%

🧩 Decompiling the data md
Most of the 3 MB ROM is data, not code — Goal 1 conquered the machine, these tracks conquer the game. Hub for the RE tracks (graphics, audio, scripts, maps, tables), unified by the round-trip rule encode(decode(bytes)) == bytes, with the emulator as the dynamic-RE instrument.
💬 Scripts & events md
Dialogue text (char table + control codes) and the event system that drives the game — extracted into a readable dump.
🎨 Graphics format md
Tiles, palettes, sprites, battle backgrounds, font & the graphics compression — round-tripped.
🔊 Audio format md
The SPC player (Goal 2a) + the ROM-side music data: song sequences, BRR instruments, SFX.
✨ Stretch goals — deliverable-driven RE md
The fun face of the data tracks: a psychedelic battle-background player, an animated bestiary, a pannable whole-world map poster, the EarthBound screenplay, an instrument soundboard, a battle sandbox, and the capstones — a randomizer & a locally-generated Almanac. Each toy secretly cracks a format.
🛠️ Post-decomp: patches & emulator hacks md
Building on top of mastery — ROM romhacks (bugfix, QoL, rebalance, randomizer; shipped as patches) and emulator hacks (widescreen, save-states, shaders, cheats) that only we can do.
🎭 LLM remix — rewrite the game md
An LLM regenerates EarthBound's writing in its own voice (Caviar Yogurt, Hákarl Yogurt with Brennivín Reduction…) and injects it as a patch. Pulls the scripts track; sibling of LLM-plays.
🚀 Crazy ideas md
Off-the-rails brainstorm (grok heavy + Racha): VR battle arenas, LLM NPCs, EarthBound⇆Home-Assistant, memory cartography, git-for-savestates, the infinite dream engine. Cranked to 11.

Companion apps & observability

🕹️ Companion apps md
Three planned desktop apps built on data we've already mapped — a live music jukebox (SPC700 + S-DSP), a save-file report card (reads the SRAM into a character sheet), and a live debug HUD (a second window of SNES internals during make play). Each with a definition of done.
🤖 LLM plays EarthBound md
An agent harness: an LLM authors sandboxed Lua that reads memory (read-only), sees the screen & presses buttons — then revises its own script.
🥧 EarthBound on a Raspberry Pi md
Platform-port goal: run make play on a Pi 4/5 game box — GLES/framebuffer render path, perf tuning, gamepad-first, EmulationStation launch.
🎯 Accuracy via test ROMs md
Raise fidelity against hardware truth — run SNES accuracy test ROMs (AccuracyCoin-style) & even author our own with the Goal-1 assembler. No second emulator to trust.
⏺️ Input recording & replay md
A TAS format: record frame→joypad logs so a human or the LLM agent's playthrough replays byte-for-byte — reproducible bugs + automated regression.
