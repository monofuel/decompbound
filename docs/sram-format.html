EarthBound SRAM format

The 8 KB battery save, mapped so far — the block the game writes when you call Dad. partially reverse-engineered

The save is 8 KB ($0000–$1FFF), persisted by play.nim to a gitignored <rom>.srm. Inspect it with make sram (sram_info.nim) and map new fields with make sram ARGS="--find <value>". Offsets below are confirmed against a real early-game save (Ness lv2: 39/39 HP, 10/10 PP, $20 on hand, $64 ATM).

Structure: the ~$60 character stride

HP/PP-like 16-bit pairs recur roughly every $60 bytes, suggesting a per-party-member struct. Only block 1 (the active char) is value-confirmed; blocks 2–4's sub-layout still needs a --find against a known second character.

Within block 1: +$00 HP cur, +$02 HP max, +$06 PP cur, +$08 PP max (relative to $023E). And every field is expected to reappear at offset + $500 in the backup copy — --find 20 hit money at both $05C and $55C.

How to map more

  1. In-game, note a value (XP, a stat, an item count, a flag).
  2. make sram ARGS="--find <value>" — see where it lives.
  3. Cross-check: change it in-game, save, re-find.
  4. Add the confirmed offset to KnownFields in sram_info.nim + this page.

Note the difference between this (the game's 8 KB battery save) and a full emulator save-state — see SRAM vs. save-states. This SRAM block is one small slice of a save-state.
